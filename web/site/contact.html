Assistance Jouer

Nous écrire

On répond à tout le monde, en général sous deux jours.

Avant d’écrire, la page d’assistance règle la plupart des cas : un code qui ne passe plus, un animateur muet, un code de connexion qui n’arrive pas, un achat à restaurer.

Elle ne sert qu’à vous répondre.

Ce qu’il advient de votre message

Il arrive dans une boîte aux lettres, et nulle part ailleurs : il n’est pas stocké sur ce site, pas analysé, pas transmis. Votre adresse sert à vous répondre, et rien d’autre. Voir la page confidentialité.

Supprimer votre compte

Pas besoin de nous écrire : Mon compte → Supprimer mon compte et mes données, dans le jeu comme dans l’application. Tout part, y compris ce qui permettrait de rouvrir le compte. Si vous préférez que nous le fassions, ce formulaire suffit.
